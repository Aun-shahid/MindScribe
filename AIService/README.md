# MindScribe AI Service

FastAPI-based microservice for AI-powered therapy session features.

## Features

- **Real-time Transcription**: WebSocket-based audio transcription using OpenAI Whisper
- **Dual Emotion Analysis**: Audio (Wav2Vec2) + Text-based emotion detection
- **SOAP Notes Generation**: Automated SOAP notes using GPT-4o-mini
- **RAG Recommendations**: Patient history-based recommendations (MongoDB integration pending)

## Setup

### 1. Install Dependencies

```bash
# Activate virtual environment
.\venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Configure Environment

Copy `.env` and fill in your API keys:

```env
OPENAI_API_KEY=sk-your-key
HF_TOKEN=hf_your-token
AI_SERVICE_SECRET_KEY=your-shared-secret-with-django
DATABASE_URL=postgresql+asyncpg://user:pass@localhost:5432/mindscribe
EMOTION_MODEL_PATH=path/to/fine_tuned_wav2vec2
PRELOAD_MODELS=false # Set to false in local dev to speed up server reloads
```

### 3. Run the Service

```bash
uvicorn src.main:app --reload --port 8001
```

## Authentication

The service uses JWT tokens generated by the Django backend. Get a token from:
```
POST http://localhost:8000/api/v1/therapy_sessions/{session_id}/start
```

Then use it in requests:
```
Authorization: Bearer <token>
```

## WebSocket Usage

Connect to the WebSocket endpoint with your token:
```
ws://localhost:8001/api/v1/session/ws/{session_id}?token=<your-token>
```

Send audio chunks:
```json
{
  "type": "audio_chunk",
  "audio_data": "<base64-encoded-audio>",
  "chunk_index": 0,
  "sample_rate": 16000,
  "format": "wav"
}
```

Receive transcriptions:
```json
{
  "type": "transcription",
  "segment": {
    "id": "seg_0001",
    "speaker": "SPEAKER_00",
    "text_urdu": "...",
    "text_english": "...",
    "emotion": {...}
  }
}
```
