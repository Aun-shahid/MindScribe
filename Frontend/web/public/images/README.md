## Color Guidelines
- **Primary Purple:** #7c3aed (purple-700) to #6b21a8 (purple-800)
- **Accent Purple:** #c4b5fd (purple-300) to #a78bfa (purple-400)
- Try to use images that complement these purple tones

## Fallback Behavior
If images are not found, the page will display:
- Gradient backgrounds with purple tones
- Icon representations of each feature
- The page will still look professional with these placeholders

## Image Optimization Tips
1. Use JPEG format for photos (smaller file size)
2. Use PNG for images with transparency or text
3. Optimize images before uploading (compress to reduce file size)
4. Ensure images are clear and professional quality

## How to Add Images
1. Place all images in this folder: `Frontend/web/public/images/`
2. Use the exact filenames listed above
3. Refresh your browser to see the images on the landing page

---

**Note:** The landing page is designed to work with or without actual images. Placeholder gradient backgrounds with icons will display until you add the real images.
